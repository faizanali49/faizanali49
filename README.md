### FaceAI  AI-powered facial analysis app

A Flutter app that scans a user's face from three angles (front, left, right) and returns a structured skin/feature analysis  an overall score, per-feature breakdown, and suggestions. It also includes a daily facial-exercise coach with video steps and timers, a hairstyle try-on feature, and a membership/paywall flow.

Built with Riverpod for state management, go_router for navigation, and Hive for offline local storage, so scan history and profile data work without needing a live connection every time. The AI analysis layer is built as its own service, kept separate from the UI, so it can be pointed at a real model/endpoint without reworking the app around it.

**GitHub:** Avalable in my repo

### Glamogo  salon booking app

A booking app for salons  users can browse salons, view services, and book an appointment for a specific time slot. Same core stack as FaceAI (Riverpod, go_router, Hive), applied to a scheduling-based flow instead of a scan-and-report flow  availability, time slots, and booking confirmation instead of cart and checkout.
